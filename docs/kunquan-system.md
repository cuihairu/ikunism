## 一、门派

- **爱坤宗**(本门,又称**坤门宗**):武学=坤拳。至高典籍《九摇坤典》,宗主原谅之后亲传。
- **形意门**(外门):「接化发」出自此门;宗主=**马宗主**(马老师)——经常输,却一身正气、平易近人,是个好老师,到处传授自己门派的功法。
- **黑门**:宗主=**黑夜**。门风/武学/与主线关系待展开(预留)。

## 二、人物

- **蔡只因**(坤拳老祖):**观看坤舞,感悟出坤拳**——坤拳的源流是舞。
- **承坤**(爱坤宗):精于坤山靠,会「连续坤闪靠」,臻至坤山靠最高境界**「坤闪靠·无影靠」**。
- **宗门圣女:蔡清滕**(爱坤宗)。
- **马宗主**(形意门):见上。
- **爱坤宗宗主**:宽恕线原谅后亲传《九摇坤典》。

## 四、传承脉络与源流考(2026-10-04 补录)

- **蔡元年**:新皇登基的纪时(纪年口径,非人名);**蔡只因**生于**蔡徐村**。
- 蔡只因创坤拳之前,学的是**知音拳**(创拳前的师承)。
- 当时的皇帝名叫**苏因**(年代背景=苏因朝)。
- **坤舞 → 坤拳**(老祖蔡只因观舞悟拳)→ **后学者学完坤拳,还要再追踪坤舞**——武学追寻是一个回环:拳的尽头是舞。与「斗舞=宗门对战语汇」(gameplay-v3 M1-duel)同源呼应:坤拳练到头,回到舞里去。追踪坤舞的落地位(剧情任务/终局追求/百戏楼斗舞场)待展开。
