## 三个方向

| 方向 | 形状语言 | 优势 | 代价 |
| --- | --- | --- | --- |
| [A 圆胖 Q 版](./direction-a-round/) | 身体一体成蛋圆形,大头大眼、短翅膀短脚、腮红 | 最萌最「吉祥物」,32px 轮廓最可读 | 拟人动作空间小 |
| [B 拟人站姿](./direction-b-standing/) | 头/身/四肢分离,明确站姿,红色运动头带+拳脚 | 最能承载坤拳招式演出(化坤手/坤闪靠/风神腿),格斗与斗舞关表现力最强 | 32px 细节偏多,量产需出简化档 |
| [C 梗图感扁平](./direction-c-flat/) | 粗描边+极简五官,坐地蛋形身,贴纸语言 | 梗图传播性最强、最「沙雕」,适合表情包与社交传播 | 演出层级表现弱于 A/B |

每个方向下四态,文件名沿用 `docs/asset-naming-conventions.md` 的角色命名:

- `chick_idle.svg` — 平静待机
- `chick_happy.svg` — 开心
- `chick_hyped.svg` — 上头
- `chick_broken.svg` — 破防

SVG 均为 `viewBox="0 0 128 128"` 矢量源,`preview.html` 内的 32/64/128px 三档为同源的尺寸可读性预览(浏览器直接缩放,未做位图降级);量产时按 `docs/ai-asset-import-rules.md` 重新导出位图。

## 合规(docs/compliance.md 红线)

- 三个候选均为**原创卡通小鸡**,不含指向真人的词汇与形象。
- 刻意**规避「背带裤+中分头+篮球+抖肩」指向性组合**(compliance 元素风险分级中的高风险组合);角色本体不带篮球道具,篮球是玩法层物件(`ball_basic`),不与角色签名物叠加。
- 方向 A 头顶呆毛为单根羽毛卷,不是发型指向;方向 B 头带为通用体育配件,不是头饰发型;方向 C 纯几何扁平无任何配件与动作指向。
- 角色名与文件名只用 `chick_*`,不含真人相关词。

## 挑选后流程

1. 用户选定方向(或指定混搭/改稿方向)。
2. 按 `docs/art-tools.md` 工作流批量出四态 + 动作(动作集见 `docs/asset-naming-conventions.md`)。
3. 过 `docs/ai-asset-import-rules.md` 导入规则(裁切/压缩/尺寸适配)。
4. 按 `docs/asset-naming-conventions.md` 命名进正式资产目录;通过后清掉本候选目录。

对应 `docs/art-tools.md`「实际工作流」第 1 步「先确定一只主角小鸡的标准外观」,即 `README.md` 路线图第 4 条的前半段。
